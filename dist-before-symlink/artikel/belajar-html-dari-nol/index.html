Belajar HTML dari Nol

Panduan dasar HTML untuk pemula.

25 Oktober 2026•2 menit baca

HTML (HyperText Markup Language) adalah bahasa markup standar yang digunakan untuk membuat dan menyusun struktur dasar halaman serta konten suatu website di peramban internet. [1, 2]

Fungsi Utama HTML

  • Menyusun Kerangka Web: Mengatur tata letak bagian-bagian halaman seperti header, menu navigasi (nav), konten utama, hingga bagian kaki (footer). [1]

  • Menampilkan Konten: Memuat teks, gambar, video, audio, dan elemen multimedia lainnya. [1]

  • Membuat Hyperlink: Menghubungkan satu halaman web ke halaman atau situs lain melalui tag khusus (<a>). [1]

  • Menyediakan Elemen Semantik (HTML5): Memberikan informasi yang lebih jelas kepada mesin pencari (SEO) dan perangkat aksesibilitas melalui tag seperti <article>, <section>, dan <aside>. [1]

Karakteristik Penting

  • Bukan Bahasa Pemrograman: HTML tidak memiliki logika pemikiran, perulangan, atau fungsi dinamis; fungsinya murni untuk penandaan (markup) dan pengaturan struktur. [1, 2]

  • Diciptakan oleh: Tim Berners-Lee pada tahun 1991 di CERN. [1, 2]

  • Didukung Teknologi Lain: Dalam pengembangan web modern, HTML selalu dipadukan dengan CSS (Cascading Style Sheets) untuk mengatur tampilan/gaya dan JavaScript untuk menambahkan interaksi. [1]
